## 説明
このゲームは、Godot エンジンを使用して作成されたシンプルなシューターゲームです。プレイヤーはキャラクターを操作し、敵を撃ちます。目標はできるだけ長く生き残り、高得点を目指すことです。

## セットアップと実行
1. Godot エンジンを [https://godotengine.org/](https://godotengine.org/) からダウンロードしてインストールします。
2. このリポジトリをローカルマシンにクローンします。
3. Godot エンジンでプロジェクトを開きます。
4. Godot エディタで再生ボタンを押してゲームを実行します。

## 操作方法とゲームプレイ
- 矢印キーまたは WASD キーを使用してプレイヤーキャラクターを移動します。
- スペースバーまたはファイアボタンを押して射撃します。
- 敵の攻撃を避け、できるだけ長く生き残ります。
- パワーアップを集めてスコアと能力を向上させます。
